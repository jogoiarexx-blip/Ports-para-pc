Final Fight X Native C++ v0.3.10 - Portable Windows x64

CORRECAO PRINCIPAL DESTA VERSAO
- Tela de selecao de personagens refeita para ser totalmente dinamica.
- A arte original select.gif continha Guy/Cody/Haggar fixos e foi removida da interface ativa de selecao.
- Ao usar ESQUERDA/DIREITA agora mudam juntos: rosto, nome e preview do personagem.
- A roleta mostra personagem anterior <- atual -> proximo.
- Funciona para P1, P2 e P3.

COMO ABRIR
1. Extraia esta pasta completa.
2. Execute FinalFightX.exe.
3. Nao mova o EXE para fora da pasta: a pasta assets deve permanecer ao lado dele.

ATALHOS
- F11 ou Alt+Enter: alterna tela cheia.
- Controles de teclado e gamepad podem ser configurados no menu principal.
